# Learning Path Designer Skill

## When to Use This Skill

- User says they want to learn a new skill, topic, or subject  
- User asks for a study plan, roadmap, or step-by-step learning guide  
- User needs curated resources, progression stages, or practice ideas  
- User requests guidance on improving or mastering a topic  

## How This Skill Works

1. **Assess the topic**: Understand what the user wants to learn and their skill level (if provided).  
2. **Break content into stages**: Divide the topic into beginner, intermediate, and advanced levels.  
3. **Recommend resources**: Provide links, book titles, videos, or tools (no paid materials unless asked).  
4. **Create practice tasks**: Assign exercises or mini-projects that reinforce each stage.  
5. **Give estimated timelines**: Offer a realistic duration for each stage based on complexity.  

## Output Format

Provide:
- **Topic Overview**: 2–3 sentence explanation of the subject.  
- **Learning Stages**: Beginner → Intermediate → Advanced (each with goals).  
- **Recommended Resources**: Books, videos, articles, or tools for each stage.  
- **Practice Exercises**: Actionable tasks with increasing difficulty.  
- **Estimated Timeline**: Rough duration for each stage, depending on commitment level.  

## Example

**Input**: “Help me create a learning path for video editing.”

**Output**:
- **Topic Overview**: Video editing involves cutting footage, arranging scenes, adding effects, and producing polished content for platforms like YouTube, TikTok, and film.  
- **Learning Stages**:  
  **Beginner** – Learn basic editing tools, timeline navigation, cuts, audio sync.  
  **Intermediate** – Master transitions, color grading, sound design, story flow.  
  **Advanced** – Work with cinematic techniques, motion graphics, advanced color correction.  
- **Resources**:  
  - Beginner: “Premiere Pro Basics” tutorial series  
  - Intermediate: Color grading courses, audio design guides  
  - Advanced: Motion graphics workshops, film editing breakdowns  
- **Practice Exercises**:  
  - Beginner: Edit a 30-second vlog clip  
  - Intermediate: Create a 1-minute cinematic montage  
  - Advanced: Produce a full short film with effects  
- **Estimated Timeline**: 6–10 weeks depending on tool familiarity and daily practice
